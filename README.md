# app-rencontre

Application de rencontres amoureuses pour la communauté kamite.

- Plateforme : Android et iOS
- Framework : Flutter / Dart
- Backend : Firebase

Voir le cahier des charges complet : [docs/cahier-des-charges.md](docs/cahier-des-charges.md)

Ce projet est indépendant de NEEGUI et du site e-commerce (La Boutique). Ne jamais mélanger les dépôts, les comptes de service ou les bases de données entre ces projets.
